# Фича: напоминания о ТО в Telegram-боте («Орландо-Механик» пишет первым)

## Цель (слова владельца, 23.10.2026)

Бот сам напоминает, что скоро замена масла/КПП/расходников/ТО — по времени И по пробегу, считая от **последней фактической** замены (из сервисной книжки). Охват — всё техобслуживание, не только масло. Если пункт регламента уже сделан раньше срока — не пинговать как «просрочено», а спокойно показать «делали тогда-то, всё нормально».

## Решения (приняты 23.10.2026, без вопросов владельцу)

- **Срок считается от последней реальной замены**, а не от календарных ТО-1/2/3. Сделал раньше срока — счётчик начался заново, статус «в порядке».
- **Интервалы — таблица в коде** `lib/maintenance-plan.ts`: пункт · интервал км · интервал мес · откуда цифра (метка) · как узнавать «сделано» (ключевые слова по `works`/`materials`). Метки: `завод` (подтверждено документом) · `сервисы` (регламенты ТО-сайтов) · `форум` · `по вашей истории`. Слово «официальный» бот не говорит, если метка не `завод` (правило из `lib/ask.ts`).
- **Конфликты источников:** для критичного (масло двигателя, ремень ГРМ, тормозная жидкость) берём более ранний срок — напомнить раньше безопаснее; для некритичного (свечи, фильтры, антифриз) — типовой сервисный, чтобы не спамить (вы свечи реально меняли через ~120 тыс.). Показываем диапазон: ремень ГРМ 90 тыс./6 лет (auto.ru, Orlando II) против 150 тыс./10 лет (to-club); по вашей истории менялся через ~75 тыс. км (120 256 → 195 300). Свечи 30–60 тыс. Масло АКПП: официального для 6T40 нет; по вашей истории ~46–50 тыс. км (2020 → 2025).
- **Текущий пробег** — оценка: последний пробег из книжки + средний темп (км/сут по записям за последние ~2 года) × дней с последней записи. Помечается «≈, оценка». Владелец отвечает числом на сообщение бота — пробег сохраняется (`odometer_readings`), оценка заменяется фактом.
- **Рассылка:** Vercel Cron раз в сутки → `/api/cron/reminders` (секрет `CRON_SECRET`) → не чаще одного напоминания по пункту за «ступень» (скоро / просрочено) + недельной сводки нет: «План ТО» — по кнопке, напоминание — когда реально подходит срок. Журнал отправленного — таблица `reminder_log`. Никакого спама.
- Кнопка в меню «🔔 План ТО» — таблица по запросу (всё по пунктам: когда делали, когда следующий, статус).
- Профиль: F18D4 1.8 бензин, ремень (не цепь), АКПП 6T40, 2012 г. (`CAR_PROFILE`).

## Не входит

Шины/АКБ/колодки (по состоянию, не по регламенту), ОСАГО/техосмотр/налог (другой тип напоминаний — отдельной фичей, если понадобится), мульти-пользователи.

## Фазы

### Фаза 1: движок расчёта + «План ТО» по запросу ✅ (23.10.2026, локально; на проде после push)
`lib/maintenance-plan.ts` (таблица пунктов + `computeStatus(records, today, odometer?)` — чистая функция), кнопка «🔔 План ТО» в боте (богатое сообщение: таблица + блок «в порядке»). Проверка скриптом `scripts/maint-check.ts` на реальной истории: каждый пункт → последняя запись, на которую он опирается, дата/пробег, следующий срок.
**Критерий:** по реальной истории масла двигателя, ГРМ, свечей, АКПП находится верная «последняя замена»; арифметика сроков сходится со скриптом; сделанное до срока не помечается просроченным.

### Фаза 2: пробег + рассылка 🟨 (код готов и проверен локально 23.10.2026; осталось: миграция 0006 в SQL Editor, CRON_SECRET в Vercel, push)
Таблицы `odometer_readings`, `reminder_log` (SQL-миграция — выполняет владелец в SQL Editor, как `bot_pending`); ввод пробега ответом числом; `app/api/cron/reminders/route.ts` + `vercel.json` (cron раз в сутки) + `CRON_SECRET` в Vercel.
**Критерий:** тестовый вызов крона с секретом шлёт напоминание владельцу один раз; повторный вызов в тот же день ничего не шлёт; без секрета — 401.

### Фаза 3: проверка на проде ⬜
Прогон на проде, security review маршрута крона, обновление README/CLAUDE.md, запись в память.

## Риски

- Сопоставление «что делали» с пунктами регламента по ключевым словам: ошибётся на нестандартных формулировках → в сообщении всегда показывается, по какой записи посчитано (проверяемо глазами).
- Оценка пробега неточна, если ездили заметно больше/меньше обычного → поэтому «≈» и просьба ввести реальный.
- Интервалы без документа завода — не истина, а ориентиры; владелец сверяет с бумажной книжкой.
