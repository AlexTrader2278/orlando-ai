# Фича: запись работ по фото документа (29.10.2026)

Просьба владельца: «надо распознавание текста прикрутить, чтобы всего не писать».

**Решение:** фото (или картинка файлом) → `lib/photo.ts` (Gemini 2.5 Flash через OpenRouter, как для голоса) → текст → существующий `parseFreeText` → превью «Проверь запись» → «✓ Сохранить». Подпись к фото дописывается в текст (пробег). GitHub (29.10): готового «фото в Telegram → строки накладной» не найдено, зрелые аналоги — общий приём «картинка → LLM → JSON», он у нас уже есть в стеке.

**Проверено (локально, реальное фото заказ-наряда №7993):** 2 работы, 9 позиций (11 шт), сумма материалов по строкам = 6 000 = итог документа, работы 10 000, всего 16 000. Обычный разбор словами не сломан (2 прогона).

**Грабли:** нейросеть потеряла ноль в номере документа (проверить скриптом нельзя) — номер пишем без ведущих нулей, в превью напоминание сверить цифры с бумагой. Пробега на документах обычно нет — подсказка «пришли фото с подписью “пробег …”».

**Не проверено:** живая отправка фото боту в Telegram (владелец).
